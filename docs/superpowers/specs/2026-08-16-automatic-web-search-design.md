# OpenJarvis 자동 인터넷 검색 설계

## 목표

`jarvis chat`에서 평범한 대화는 지금처럼 자연스럽게 이어가되, 장소 추천,
영업시간, 날씨, 교통, 가격처럼 현재 정보가 필요한 요청은 조비서가 별도 확인
질문 없이 자동으로 인터넷을 검색한다. 검색하지 않은 최신 정보나 실제 장소를
추측해 만들지 않는다.

## 현재 상태와 원인

- `web_search` 도구와 무료 DuckDuckGo 대체 검색은 이미 설치되어 있다.
- 현재 기본 대화 담당은 `simple`이며 도구 호출을 지원하지 않는다.
- 설정에는 여러 도구가 활성화되어 있지만 `simple`은 이를 전달받지 않는다.
- 따라서 문제는 검색 기능 부재가 아니라 기본 대화 담당과 검색 도구의 연결 부재다.

## 선택한 접근

기본 대화 담당을 도구 호출을 지원하는 `orchestrator`로 바꾸고, 기본 대화에는
`web_search`만 제공한다. 모델은 평범한 잡담에는 도구를 호출하지 않고 바로
답하며, 최신 정보가 필요한 경우 검색 도구를 호출한 뒤 결과를 바탕으로 답한다.

이 방식은 낱말 목록만으로 검색을 강제하는 규칙식 분류보다 표현 변화에 강하고,
별도 모델이 매번 검색 여부를 판별하는 방식보다 빠르고 메모리 사용량이 작다.

## 검색 정책

다음 요청에는 인터넷 검색을 우선한다.

- 식당, 카페, 상점, 관광지 등 실제 장소 추천
- 영업시간, 휴무일, 입장료, 가격, 예약 가능 여부
- 날씨, 교통, 행사, 일정처럼 시간이 지나면 달라지는 정보
- 사용자가 최신 정보나 확인 가능한 출처를 요구하는 경우

다음 요청은 기본적으로 검색하지 않는다.

- 인사, 잡담, 감정 표현과 말동무 대화
- 사용자가 이미 제공한 내용의 요약이나 정리
- 찬우의 의도나 심리를 이해하기 위한 대화
- 개인 기억을 해석하는 작업

개인적인 맥락이 불명확하면 인터넷 검색보다 찬우에게 묻는 기존 원칙을 유지한다.

## 도구와 안전 경계

- 기본 도구 목록은 `web_search` 하나로 제한한다.
- 파일 읽기, 명령 실행, 코드 실행은 자동 검색 대화에 노출하지 않는다.
- 사용자가 명령줄에서 `--tools`를 명시하면 해당 대화에 한해 다른 도구를 사용할
  수 있는 기존 기능은 유지한다.
- Tavily 열쇠가 없으면 설치된 DuckDuckGo 대체 검색을 사용한다.
- 검색 실패 시 구체적인 장소나 운영 정보를 지어내지 않고, 검색 실패와 확인이
  필요한 항목을 분명히 알린다.

## 답변 형식

장소 계획 요청에는 가능한 범위에서 다음 내용을 제공한다.

1. 시간순 일정
2. 장소 이름과 선택 이유
3. 주소 또는 위치 설명
4. 확인된 운영시간과 휴무 정보
5. 장소 사이 이동 순서와 예상 이동 부담
6. 확인에 사용한 출처 링크

출처가 서로 다르거나 최신 여부가 불확실하면 그 사실을 함께 표시한다.

## 처리 흐름

1. 사용자가 `jarvis chat`에 요청을 입력한다.
2. 대화 담당이 요청과 `web_search` 도구 설명을 함께 본다.
3. 최신 정보가 필요 없으면 바로 답한다.
4. 최신 정보가 필요하면 하나 이상의 검색어로 검색한다.
5. 검색 결과를 대화 담당에게 돌려준다.
6. 대화 담당이 출처에 근거한 일정이나 추천을 작성한다.
7. 완성된 대화는 기존 개인 기억 흐름에 따라 로컬에 보관된다.

## 오류 처리

- 검색 결과 없음: 검색어를 한 번 구체화해 재시도하고, 그래도 없으면 알린다.
- 검색 도구 오류: 오류 내용을 짧게 알리고 추측 답변을 만들지 않는다.
- 영업시간 충돌: 서로 다른 출처를 표시하고 방문 전 확인을 권한다.
- 도구 호출 반복: 기존 최대 반복 횟수와 반복 방지 장치를 그대로 사용한다.

## 검사와 완료 기준

- `jarvis chat` 시작 화면의 기본 담당이 `orchestrator`로 표시된다.
- 기본 제공 도구는 `web_search` 하나다.
- 인사 같은 평범한 대화에서는 검색 도구가 호출되지 않는다.
- 최신 장소 계획 요청에서는 검색 도구가 호출된다.
- 검색 결과가 답변에 반영되고 출처 링크가 포함된다.
- 검색 실패 시 만들어낸 장소 없이 실패 사실을 답한다.
- 개인 기억 관련 기존 검사가 계속 통과한다.
- 사용자가 제공한 대전 일정 예시를 실제로 입력해 검색 동작을 확인한다.

## 범위 밖

- 지도 화면이나 실시간 길찾기 연동
- 식당 예약이나 결제
- 사용자의 현재 위치 자동 수집
- 외부 서비스 계정 연동
- 검색 결과를 개인 성격 도식으로 자동 확정하는 기능
